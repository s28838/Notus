# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent dark mode toggle to the Profile page, driven by a `data-theme` attribute on `<html>` and CSS variable overrides.

**Architecture:** A new `ThemeContext` manages theme state in `localStorage` and writes `data-theme="dark"` to `document.documentElement`. CSS variable overrides in `styles.css` under `[data-theme="dark"]` adapt all stitch-theme components automatically. Four components with hardcoded background colors get explicit dark overrides.

**Tech Stack:** React 18, plain CSS variables, `localStorage`

## Task 2: ThemeContext

**Files:**
- Create: `src/context/ThemeContext.jsx`

- [ ] **Step 1: Create the file**

Create `src/context/ThemeContext.jsx` with this content:

```jsx
import React, { createContext, useContext, useState, useEffect } from "react";

// Apply theme synchronously when module loads to prevent flash on refresh
const savedTheme = localStorage.getItem("theme");
if (savedTheme === "dark") {
  document.documentElement.setAttribute("data-theme", "dark");
}

const ThemeContext = createContext(null);

export const ThemeProvider = ({ children }) => {
  const [isDark, setIsDark] = useState(() => localStorage.getItem("theme") === "dark");

  useEffect(() => {
    if (isDark) {
      document.documentElement.setAttribute("data-theme", "dark");
      localStorage.setItem("theme", "dark");
    } else {
      document.documentElement.removeAttribute("data-theme");
      localStorage.setItem("theme", "light");
    }
  }, [isDark]);

  const toggleTheme = () => setIsDark((prev) => !prev);

  return (
    <ThemeContext.Provider value={{ isDark, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

export const useTheme = () => useContext(ThemeContext);
```
